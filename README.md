# Подземелье: Текстовая Ролевая Игра

## Описание
"Подземелье" — это текстовая ролевая игра, 
в которой игрок управляет персонажем, путешествующим 
по случайно сгенерированным уровням подземелья. 
На каждом уровне вы столкнетесь с монстрами, 
ловушками и случайными событиями, сражаясь за 
выживание и собирая награды;

## Основные особенности
- **Генерация подземелья:** каждое подземелье уникально благодаря случайной генерации комнат;
- **Бои с монстрами:** встречайте разнообразных врагов, включая гоблинов, скелетов и даже драконов, с уникальными характеристиками;
- **Магазин:** покупайте зелья и свитки, используя собранные монеты;
- **Тактические бои:** игрок может атаковать, блокировать, лечиться или пытаться сбежать из боя;
- **Система инвентаря:** собирайте предметы, чтобы выжить в опасных подземельях;

## Установка
1. Убедитесь, что у вас установлен Python 3.7 или выше;
2. Скачайте файл игры;
3. Запустите файл с помощью команды:
   ```powershell(ну или bash, любая консоль)
   python dungeon_game.py
   ```

## Как играть
1. Введите имя персонажа, чтобы начать игру;
2. В главном меню выберите:
   - `1` для входа в подземелье;
   - `2` для посещения магазина;
   - `3` для выхода из игры;
3. В подземелье вы будете встречать комнаты, которые могут содержать:
   - пустые комнаты;
   - монстров;
   - ловушки;
   - спуски на следующий уровень;
4. В битве с монстрами выберите одно из действий:
   - **1. Атака** — наносите урон врагу;
   - **2. Блок** — попробуйте заблокировать атаку;
   - **3. Лечение** — используйте зелья для восстановления здоровья;
   - **4. Сбежать** — попробуйте покинуть бой;
5. Убивайте монстров, чтобы зарабатывать монеты и покупать полезные предметы в магазине.

# Основные классы
### 1. `Player`
- Описание: класс игрока, содержащий здоровье, силу атаки, инвентарь и монеты;
- Методы:
  - `attack(target)` — атакует цель, нанося случайный урон;
  - `take_damage(damage)` — уменьшает здоровье игрока при получении урона;
  - `is_alive()` — проверяет, жив ли игрок;

### 2. `Monster` (подклассы: `Goblin`, `Dragon`, `Skeleton`)
- Описание: базовый класс для всех врагов.
- Атрибуты: здоровье, сила атаки, шанс промаха, награда за убийство(монеты);
- Методы:
  - `attack(target)` — атакует цель с шансом промахнуться;
  - `take_damage(damage)` — уменьшает здоровье монстра при получении урона;
  - `is_alive()` — проверяет, жив монстр или нет;

## 3. `Dungeon`
- Описание: класс подземелья, который генерирует случайную комнату;
- Методы:
  - `generate_map()` — cоздает карту подземелья с 5 случайными комнатами;
  - `handle_room(player, room)` — обрабатывает события в текущей комнате;
  - `battle(player, monster)` — запускает битву между игроком и монстром;
